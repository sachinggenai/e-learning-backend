# API

## Base

- Framework: FastAPI
- Entrypoint: `app/main.py`
- Base prefix: `/api/v1`
- Interactive docs: `/docs`

## Canonical Contracts

These are the backend routes currently treated as canonical for FE/BE integration on the SCORM export contract branch.

### Scoring

- Method: `POST`
- Path: `/api/v1/courses/{courseId}/scoring/calculate`

Request body:

```json
{
	"answers": [
		{
			"componentId": "component-1",
			"componentType": "mcq",
			"responses": [
				{
					"questionId": "q1",
					"selectedOptionIds": ["option-a"]
				}
			]
		}
	],
	"attemptNumber": 1
}
```

Success response shape:

```json
{
	"totalScore": 100,
	"maxScore": 100,
	"percentage": 100,
	"passed": true,
	"passingScore": 70,
	"componentResults": [
		{
			"componentId": "component-1",
			"componentType": "mcq",
			"score": 100,
			"maxScore": 100,
			"weight": 1.0,
			"weightedScore": 100,
			"questionResults": [
				{
					"questionId": "q1",
					"correct": true,
					"score": 100,
					"maxScore": 100,
					"partialCredit": false
				}
			]
		}
	],
	"attemptNumber": 1,
	"remainingAttempts": null
}
```

### Page Completion

- Method: `POST`
- Path: `/api/v1/courses/{courseId}/pages/{pageId}/completion`

Request body:

```json
{
	"componentStates": [
		{
			"componentId": "component-1",
			"completed": true,
			"interactionsCompleted": ["interaction-1"],
			"audiosCompleted": [],
			"score": 80
		}
	]
}
```

Success response shape:

```json
{
	"pageId": "page-1",
	"title": "Assessment Page",
	"completed": true,
	"strategy": "all",
	"components": [
		{
			"componentId": "component-1",
			"completed": true,
			"completionType": "score",
			"threshold": 70
		}
	]
}
```

### Interactions

- Method: `POST`
- Path: `/api/v1/courses/{courseId}/interactions`

Request body:

```json
{
	"pageId": "page-1",
	"componentId": "component-1",
	"interactionType": "click",
	"learnerId": "learner-1",
	"data": {
		"interactionId": "click-1",
		"value": "cta-button",
		"duration": 1.2,
		"isCorrect": true,
		"score": 100,
		"maxScore": 100
	},
	"completed": true
}
```

Notes:

- `interactionType` is intentionally an open string.
- Interaction events are persisted and can be queried through `GET /api/v1/courses/{courseId}/interactions`.

### Persisted SCORM Export

- Method: `POST`
- Path: `/api/v1/export/scorm/{courseId}?format=scorm_1_2`
- Response: `application/zip`

ZIP contents:

- `imsmanifest.xml`
- `index.html`
- `course_data.js`
- `styles.css`
- `scorm_wrapper.js`
- `asset_manifest.json`

Export metadata emitted in `course_data.js`:

```json
{
	"courseId": "course-001",
	"exportContractVersion": "2026-04-12.1",
	"supportedTemplateTypes": ["accordion", "tabs", "mcq"]
}
```

## Error Envelope

Canonical error shape for contract-facing endpoints:

```json
{
	"code": "ERROR_CODE_CONSTANT",
	"field": "path.to.field",
	"message": "Human-readable summary",
	"details": {
		"context": "additional machine-readable detail"
	}
}
```

Common codes:

- `INVALID_JSON`
- `VALIDATION_ERROR`
- `NOT_FOUND`
- `STATE_ERROR`
- `INTERNAL_ERROR`

Example:

```json
{
	"code": "NOT_FOUND",
	"field": "courseId",
	"message": "Course 'missing-course' not found",
	"details": {}
}
```
